# MEDI ALPHA PLUS — 法人向け尿検査キット LP

## プロジェクト概要

医療機関・健診会社・検査センター・研究機関向けの  
**法人大口見積依頼・継続利用相談・定期納品相談を最大化する**ランディングページ。

会社概要サイト（https://www.medialphaplus.com/index.html）のブランドトーンを継承しながら、  
「Bright Clinical Premium」デザインコンセプトで全面刷新。

## 実装済み機能

### セクション構成
1. **ヘッダー** — 固定ナビ・SPハンバーガーメニュー・スクロール時シャドウ
2. **ファーストビュー (Hero)** — 2カラム構成・「キット、もう」大見出し・KPI4枚・主副CTAの優先順位設計
3. **信頼バー** — 認証・日本製・請求書払い・全国配送を即時伝達
4. **課題提起** — 6課題カードUI＋課題解決バナーCTA
5. **5つの強み** — 交互レイアウト（コスト比較ビジュアル・安定供給・品質可視化）
6. **商品仕様** — ラベルあり/なし切替・詳細仕様テーブル
7. **価格表** — 内製比較バー + タブ別数量価格表 + なぜ安いかの説明
8. **法人大口訴求** — ネイビーセクション・3要素相談カード
9. **品質・供給体制** — 7項目の信頼カード（認証・UN3373・日本製・ロット管理等）
10. **導入実績** — KPIパネル×4 + 大口実績カード + 業種一覧 + 事例カード×3 + 声×4
11. **中間CTA** — ページ中盤に自然な見積誘導
12. **FAQ** — アコーディオン式10問（Q&A追加で拡張可）
13. **見積フォーム** — バリデーション・送信完了モーダル・安心訴求サイドバー
14. **フッター** — 会社リンク・注記・著作権
15. **SP固定CTA** — ヒーロー通過後に表示・見積＋電話ボタン

### JavaScript機能
- スクロールアニメーション（IntersectionObserver・Stagger対応）
- FAQアコーディオン
- 価格タブ切替（ラベルあり/なし）
- 商品サムネイル切替（フェードイン）
- KPIカウンターアニメーション
- コスト比較バーアニメーション
- フォームバリデーション（リアルタイム）
- 送信完了モーダル（Escape・外側クリックで閉じる）
- ヘッダーアクティブナビ
- SP固定CTAの表示制御
- スムーススクロール（ヘッダー高さ考慮）
