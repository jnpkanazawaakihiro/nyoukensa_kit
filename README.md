# 尿検査キット 法人向け LP｜MEDI ALPHA PLUS

## プロジェクト概要

**目的:** 尿検査キットの法人大口受注を最大化するための、広告流入特化ランディングページ  
**主CTA:** 無料見積依頼フォーム（法人向け）  
**副CTA:** 商品ページへの直接購入リンク（お試し100セット）

---

## 完成済み機能

### ページ構成
1. **ヘッダー** - 固定ナビ・モバイルハンバーガーメニュー・見積依頼CTAボタン
2. **ヒーロー** - 背景画像・主要訴求・信頼スコア・デュアルCTA
3. **課題提起セクション** - 6つの課題カード・解決バナー
4. **強みセクション** - 5つの強みを画像付き交互レイアウトで表示
5. **セット内容セクション** - バリアント切替（ラベル有/無）・スペック・価格
6. **価格表セクション** - タブ切替・コスト比較バー・なぜ安いのか説明
7. **法人特価セクション** - 3つのポイント・メリット・見積依頼CTA
8. **導入事例セクション** - 3業種・信頼数値（カウントアップ）
9. **FAQセクション** - アコーディオン8項目
10. **見積依頼フォーム** - メイン主CTA・送信完了表示
11. **フッター** - リンク・会社情報・連絡先
12. **固定CTA** - スクロール後に表示される下部バー
13. **TOPへ戻るボタン**

### インタラクション
- スクロールアニメーション（フェードイン）
- FAQアコーディオン
- 価格タブ切替（ラベル有/ラベルなし）
- 商品バリアント画像切替
- コスト比較バーアニメーション
- カウントアップ数値アニメーション
- フォームバリデーション・送信完了表示
- モバイルハンバーガーメニュー
- スムーズスクロール

## 未実装・推奨ネクストステップ

### 必須（広告強化前に対応推奨）
1. **フォームのバックエンド連携** - 現状はモック。実際にはShopify Contact Form API・Formspree・Mailchimp等へPOSTする実装が必要
2. **独自ドメイン化** - `myshopify.com`から独自ドメインへ変更（B2B信頼性）
3. **Google Analytics / Meta Pixel 設置** - 広告計測のために必須
4. **OGP設定** - SNS・広告でのリンクプレビュー最適化

### 推奨
5. **実際の顧客声（テキスト証言）追加** - 具体名・役職付きの声で信頼性強化
6. **導入社数・取引実績の具体数値追加** - 「○社導入済み」などの第三者証明
7. **商品の高品質写真追加** - フラットレイ・使用シーン・ラベル拡大写真
8. **A/Bテスト設定** - ヒーローコピー・CTA文言の最適化
9. **チャットウィジェット追加** - リアルタイム問い合わせ対応
